# План работ и журнал

## Цель

Инструмент, который по теме набора и пожеланиям продюсера выдаёт 3–5 вариантов набора из 10 карточек (только картинки объектов, без вёрстки окон). Публичный репозиторий, промпты и скилл для Claude Code, генерация через Gemini image API.

## Архитектура

- **Мозг**: Claude Code со скиллом `/card-set`. Планирует сет (JSON), собирает промпты из шаблонов по категориям, оценивает кандидатов глазами, собирает варианты, пишет отчёт.
- **Руки**: сменный бэкенд с общим раннером `lib/run.mjs`. `backends/gemini.mjs` вызывает Gemini `generateContent` с референс-картинками, `backends/openai.mjs` вызывает OpenAI `/v1/images/edits` (`gpt-image-2.5-flare`) с референсами. `backends/manual.mjs` выдаёт пакет промптов для ручной генерации в любом сервисе.
- **Данные**: 35 референсных карточек с разметкой по категориям, лист персонажей, правила с доски.

## Ключевые решения

- **Платный Gemini вместо бесплатного тира.** Проверено по документации 11.09.2026: image-модели недоступны на бесплатном тире. Цена ≈ $0.067 за картинку 1K (сверено 12.09), сет из 40 картинок ≈ $2.7; на OpenAI gpt-image-2.5 ≈ $0.03–0.06 за картинку. Платный тир не использует данные для обучения, для рабочих артов это плюс.
- **Два API-бэкенда с одним интерфейсом.** Gemini и OpenAI (`gpt-image-2.5-flare`, референсы через `/v1/images/edits`). Первый тест можно сделать на личном ключе OpenAI, подписка ChatGPT ключа не даёт, нужен баланс на platform.openai.com.
- **Локальная генерация не рассматривается.** У рабочей машины RTX 3050 4 ГБ, этого мало для Flux и LoRA. Бэкенд ComfyUI можно добавить позже тем же интерфейсом.
- **Промпты на английском, документация RU+EN.**
- **Тестовый сет Coolness, а не Beach.** Из Beach выгружено только 3 карты, Coolness выгружен полностью и содержит все 4 категории.
- **Формат кадра 4:5 с обрезкой до 430×480.** Gemini не умеет 9:10 напрямую.

## Критерии успеха теста (этап 4)

- Не менее 7 из 10 карт Coolness проходят QA без правок.
- Карты визуально ложатся рядом с оригиналами на общем контакт-листе.
- Персонажи на золотых картах Fishing узнаваемы как те же самые, что на референсах.

1. В сете Amusement у Ice Cream, Coaster и Duck Ride золотая рамка и 5 звёзд, но персонажей нет. Золотая карта всегда с персонажем или рамка означает только редкость?

3. Публиковать ли референсные карточки в открытом репозитории или хранить их отдельно.

## Риски

- Дрейф персонажей между картами. Смягчение: до 4 референсов персонажа на запрос, критерий `character_match` в QA, перегенерация одной карты.
- Текст и логотипы в генерациях. Смягчение: запреты в промпте, критерий в QA.
- Лимиты запросов в минуту. Смягчение: пауза между запросами, повтор при 429.
