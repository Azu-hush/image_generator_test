# Как получить ключ Gemini API (Google AI Studio)

Проверено по документации Google 11.09.2026. Ссылки на первоисточники внизу.

## Важно: бесплатного тира для генерации картинок через API нет

В таблице цен у всех image-моделей (`gemini-3.1-flash-image`, `gemini-3.1-flash-lite-image`,
`gemini-3-pro-image`, `gemini-2.5-flash-image`) в колонке «Free tier» стоит «Not available».
Бесплатно картинки можно генерировать только руками в веб-интерфейсе AI Studio или в приложении Gemini.

Что это значит для нас:

| Режим | Стоимость | Автоматизация |
|---|---|---|
| API, `gemini-3.1-flash-lite-image` | ≈ $0.034 за картинку 1K | полная |
| API, `gemini-3.1-flash-image` | ≈ $0.045 за картинку 1K | полная, лучше держит референсы (до 10 объектов, 4 персонажа, 3 стиля) |
| API, `gemini-3-pro-image` | ≈ $0.13 за картинку 1K | полная, самое высокое качество |
| Веб AI Studio / приложение Gemini | бесплатно, есть дневной лимит | ручная: копируем промпт и референсы |

Оценка на наш пайплайн: сет из 10 карт × 4 кандидата = 40 картинок ≈ $1.4–1.8 на Flash.
Коллекция из 16 сетов по 3 варианта ≈ $25–35. Тестовый сет «Coolness» обойдётся меньше $2.

Плюс платного тира: Google **не использует** промпты и картинки платного тира для обучения моделей.
На бесплатном тире (веб-интерфейс) контент используется для улучшения продуктов и его могут смотреть люди.
Для рабочих артов это аргумент в пользу API.

## Шаг 1. Создать ключ

1. Войти в Google-аккаунт и открыть <https://aistudio.google.com/apikey>.
2. При первом входе принять условия использования (это делает владелец аккаунта сам).
3. Нажать **Create API key**. AI Studio предложит создать новый проект Google Cloud или выбрать существующий.
   Для рабочего инструмента лучше отдельный проект, например `card-art-generator`.
4. Скопировать ключ. Он показывается один раз, потом только в списке без значения.

Новые ключи создаются как «auth keys», у них по умолчанию нет ограничений по API. Ограничения можно
добавить позже в Google Cloud Console → APIs & Services → Credentials.

## Шаг 2. Включить биллинг на проекте

Без биллинга проект остаётся в бесплатном тире, а в нём image-модели не работают.

1. На странице <https://aistudio.google.com/apikey> напротив проекта нажать **Set up billing**
   (или открыть <https://console.cloud.google.com/billing> и привязать платёжный аккаунт к проекту).
2. Привязать карту. Google принимает корпоративные карты, счёт приходит помесячно.
3. Сразу поставить бюджет с уведомлениями: Cloud Console → Billing → **Budgets & alerts** → Create budget,
   например $20 в месяц с алертами на 50 % и 90 %. Бюджет только предупреждает, не отключает API,
   поэтому лимит кандидатов на карту дополнительно зашит в самом инструменте.

Проверить, что тир платный: <https://aistudio.google.com/rate-limit>. Там же видны актуальные лимиты
запросов в минуту и в день для каждой модели.

## Шаг 3. Сохранить ключ на компьютере

Ключ хранится только в переменной окружения `GEMINI_API_KEY`. В репозиторий он не попадает,
`.env` добавлен в `.gitignore`.

Windows, один раз в PowerShell или cmd (после этого перезапустить терминал и Claude Code):

```bash
setx GEMINI_API_KEY "ВСТАВИТЬ_КЛЮЧ"
```

Либо через интерфейс: Пуск → «Изменение переменных среды текущего пользователя» → Создать →
имя `GEMINI_API_KEY`, значение ключ.

macOS / Linux: добавить в `~/.zshrc` или `~/.bashrc` строку `export GEMINI_API_KEY=ВСТАВИТЬ_КЛЮЧ`.

## Шаг 4. Проверить, что ключ работает

Git Bash / macOS / Linux:

```bash
curl -s -H "x-goog-api-key: $GEMINI_API_KEY" https://generativelanguage.googleapis.com/v1beta/models | grep -o '"name": "models/[^"]*image[^"]*"'
```

PowerShell:

```powershell
curl.exe -s -H "x-goog-api-key: $env:GEMINI_API_KEY" https://generativelanguage.googleapis.com/v1beta/models | Select-String image
```

Ожидаемый результат: список моделей, среди них `models/gemini-3.1-flash-image`.
Ошибка `API_KEY_INVALID` означает опечатку в ключе. Ошибка `403` или `PERMISSION_DENIED` при генерации
картинки чаще всего означает, что на проекте не включён биллинг.

## Правила безопасности

- Ключ не пересылать в чатах и не вставлять в код. Инструмент читает его только из окружения.
- Если ключ утёк, удалить его на <https://aistudio.google.com/apikey> и создать новый.
- Для общедоступного инструмента каждый пользователь заводит свой ключ, общий ключ команды не публикуется.
- Все картинки, сгенерированные Gemini, несут невидимый водяной знак SynthID. На игровой графике он не виден,
  но об этом стоит знать юристам.
