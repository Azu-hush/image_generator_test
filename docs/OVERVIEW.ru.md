# Генератор артов для коллекционных карточек: что получилось

Репозиторий: <https://github.com/Azu-hush/image_generator_test>

## Что делает

На вход: тема коллекции, тема сета и свободные пожелания продюсера. На выход: 3–5 вариантов набора из 10 карточек (PNG объектов в пропорции игровой карты 430×480) с контакт-листами и отчётом QA. Вёрстка окон не делается, картинки подставляются в игру вручную.

## Как устроен пайплайн

1. **План сета.** Claude в роли арт-директора раскладывает 10 карт по правилам с доски: категории 1–4 для объектов, категория 5 для золотых карт с персонажами, разные фоны у соседних карт, никаких повторов внутри коллекции. Результат: `plan.json`, проверяется валидатором.
2. **Промпт на карту.** Собирается из базового описания стиля, шаблона своей категории, описания объекта, списка запретов (текст, логотипы, рамки, мелкие детали) и 2–3 референсных карточек того же типа. Для золотых карт добавляются референсы персонажей.
3. **Генерация.** Сменный бэкенд: Gemini или OpenAI через API с референс-картинками, по 4 кандидата на карту. Без ключа тот же промпт выдаётся пакетом `prompt-pack.html` для ручной генерации в любом сервисе.
4. **Контроль качества.** Claude смотрит каждого кандидата и оценивает по чеклисту: объект по центру, категория соблюдена, стиль совпадает, нет текста и артефактов, читается в миниатюре, персонаж узнаваем. Провалившиеся карты перегенерируются.
5. **Сборка вариантов.** Из прошедших кандидатов собираются варианты сета: первый из лучших картинок, второй из вторых по оценке и так далее. Плюс контакт-листы и итоговый отчёт.

Всё вместе запускается одной командой скилла в Claude Code:

```
/card-set Summer "Camping" "уютное настроение, тёплые цвета, одна золотая карта с петухом"
```

## Как протестировать

**Без ключа, бесплатно, 10 минут.** Проверяет промпты и правила.

1. Склонировать репозиторий, в папке проекта выполнить `node backends/manual.mjs --plan examples/summer_fishing.plan.json`.
2. Открыть `out/summer/fishing/prompt-pack.html`. У каждой карты кнопка «copy prompt» и референсы в папке `refs`.
3. В ChatGPT или Google AI Studio приложить референсы, вставить промпт, попросить вертикальную картинку 4:5. Сделать 3–4 карты разных категорий и сравнить с оригиналами из `data/cards`.

**С ключом, около доллара, 15 минут.** Проверяет весь автоматический цикл.

1. Получить ключ OpenAI (platform.openai.com, нужен баланс) или Gemini (нужен биллинг). Гайды в `docs/`.
2. Сохранить в переменную окружения: `setx OPENAI_API_KEY "..."`, перезапустить терминал.
3. Запустить бенчмарк, 20 картинок: `node backends/openai.mjs --plan examples/summer_coolness_remake.plan.json --candidates 2`.
4. Сравнить `out/summer/coolness/candidates/` с оригинальными картами 41–50 в `data/cards`.
5. Собрать варианты: `node scripts/qa-template.mjs --set out/summer/coolness`, затем `node scripts/assemble.mjs --set out/summer/coolness`, открыть `variants/index.html`.

**Полный цикл через Claude Code.** Открыть репозиторий в Claude Code с ключом в окружении и написать команду `/card-set` с новой темой. Claude спланирует сет, покажет таблицу, сгенерирует, отсмотрит и отдаст три варианта.

## Критерии успеха теста

- Не менее 7 из 10 карт Coolness проходят QA без правок и визуально ложатся рядом с оригиналами.
- Персонажи на золотых картах Fishing узнаются как те же, что на референсах.
- Стоимость сета с 4 кандидатами на карту укладывается в 2–3 доллара.

## Ограничения и открытые вопросы

- Бесплатного тира для генерации через API нет ни у Google, ни у OpenAI; бесплатен только ручной режим.
- Персонажи Sheep и Bull без референсов в полном размере, нужны для золотых карт с ними.
- В сете Amusement есть карты с золотой рамкой без персонажей: уточнить, всегда ли золотая карта сюжетная.
