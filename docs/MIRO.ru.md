## Фрейм 1. Задача и подход

**Задача.** Инструмент, который по теме набора и пожеланиям продюсера выдаёт 3–5 вариантов набора из 10 карточек (картинки объектов, без вёрстки окон).

**Подход.** Разделили «мозг» и «руки». Мозг: Claude Code со скиллом `/card-set` планирует сет, пишет промпты по шаблонам категорий 1–5, проверяет картинки глазами и собирает варианты. Руки: Gemini image API с референс-картинками. Без ключа инструмент выдаёт пакет промптов для ручной генерации.

**Ссылка на репозиторий:** <https://github.com/Azu-hush/playrix_test>

Картинка: `docs/architecture.svg`.

## Фрейм 3. Как устроен пайплайн

```
тема + пожелания → план сета (JSON, 10 карт, категории, цвета, референсы)
→ промпт на карту = базовый стиль + шаблон категории + описание + запреты + 2–3 референса
→ N кандидатов на карту (Gemini) или пакет промптов (ручной режим)
→ QA по 5–6 критериям (центр, категория, стиль, текст/артефакты, читаемость, персонаж)
→ варианты сета: variant_1 = лучшие кандидаты, variant_2 = вторые и т.д.
→ контакт-листы + отчёт
```

Показать рядом: полоски примеров категорий с доски (`data/rules/`), один готовый промпт из `out/summer/fishing/prompts/09_big_catch.txt`, скрин `prompt-pack.html`.
