Генератор артов для коллекционных карточек

Инструмент принимает тему набора и пожелания продюсера, а отдаёт 3–5 вариантов набора из 10 карточек: картинки объектов в пропорции игровой карты, контакт-листы и отчёт контроля качества. Вёрстка окон не делается, картинки подставляются в игру вручную.

Репозиторий github.com/Azu-hush/image_generator_test Стек Claude Code + Node 20; модели Anthropic, OpenAI, Gemini на выбор для каждого этапа Формат карты 430 × 480 px
Фрейм 1

Как устроен пайплайн

Разделили «мозг» и «руки». Мозг: Claude в роли арт-директора планирует, пишет промпты, отсматривает результат и собирает варианты. Руки: сменный бэкенд генерации картинок. Без API-ключа тот же пайплайн работает в режиме репетиции и вместо картинок выдаёт пакет промптов для ручной генерации.

1

План сета

Claude раскладывает 10 карт по правилам с доски: категории 1–4 для объектов, категория 5 для золотых карт с персонажами, разные фоны у соседних карт, никаких повторов внутри коллекции. Результат: plan.json, его проверяет валидатор.

2

Промпт на карту

Базовое описание стиля, шаблон своей категории, описание объекта, запреты (текст, логотипы, рамки, мелкие детали) и 2–3 референсные карточки того же типа. Золотым картам добавляются референсы персонажей.

3

Генерация

Gemini или OpenAI через API с референс-картинками, по 4 кандидата на карту. Без ключа тот же промпт выдаётся файлом prompt-pack.html для ручной генерации в любом сервисе.

4

Контроль качества

Claude смотрит каждого кандидата по чеклисту: объект по центру, категория соблюдена, стиль совпадает, нет текста и артефактов, читается в миниатюре, персонаж узнаваем. Провалившиеся карты перегенерируются.

5

Сборка вариантов

Первый вариант из лучших картинок, второй из вторых по оценке и так далее. Плюс контакт-листы в раскладке игрового окна и итоговый отчёт.

Всё вместе запускается одной командой скилла в Claude Code:

/card-set Summer "Camping" "уютное настроение, тёплые цвета, одна золотая карта с петухом"
Фрейм 2

Правила категорий, зашитые в промпты

В каждом сете присутствуют все четыре категории объектов вне зависимости от редкости. Для каждой свой шаблон промпта и свои эталонные карточки из выгрузки.

Кат. 1В воздухеОбъект висит, фон плоский с простым узором: лучи, круги, полосы.
Кат. 2На простом полуОбъект стоит, позади ровный задник с градиентом или узором.
Кат. 3На реальной поверхностиДерево, трава, плитка; задник по-прежнему простой.
Кат. 4В окруженииУпрощённая реалистичная сцена, объект остаётся центральным.
Кат. 5Золотая карта1–2 персонажа разыгрывают ироничную сценку на фоне категории 4.
Фрейм 3

Как протестировать

Три сценария от бесплатного к полному. Первый проверяет промпты и правила, второй весь автоматический цикл, третий инструмент глазами продюсера.

Подписка ChatGPT Plus ключа API не даёт. Нужен ключ с platform.openai.com и предоплаченный баланс на нём. Ключ хранится только в переменной окружения и в репозиторий не попадает.

Без ключа

бесплатно · 10 минут
  1. В папке проекта: node backends/manual.mjs --plan examples/summer_fishing.plan.json
  2. Открыть out/summer/fishing/prompt-pack.html. У каждой карты кнопка «copy prompt» и референсы в папке refs.
  3. В ChatGPT или Google AI Studio приложить референсы, вставить промпт, попросить вертикальную картинку 4:5.
  4. Сделать 3–4 карты разных категорий и сравнить с оригиналами из data/cards.
Проверяет: попадание в стиль, соблюдение категорий, качество промптов.

С ключом API

около $1 · 15 минут
  1. Ключ OpenAI с platform.openai.com (нужен баланс) или Gemini (нужен биллинг). Гайды в docs/.
  2. setx OPENAI_API_KEY "...", перезапустить терминал.
  3. Бенчмарк, 20 картинок: node backends/openai.mjs --plan examples/summer_coolness_remake.plan.json --candidates 2
  4. Сравнить out/summer/coolness/candidates с оригинальными картами 41–50.
  5. node scripts/qa-template.mjs --set out/summer/coolness, затем node scripts/assemble.mjs --set out/summer/coolness, открыть variants/index.html.
Проверяет: автоматический цикл, стоимость, лимиты, сборку вариантов.

Полный цикл

$2–3 за сет · 20 минут
  1. Открыть репозиторий в Claude Code с ключом в окружении.
  2. Написать /card-set с новой темой и пожеланиями.
  3. Claude спланирует сет и покажет таблицу, сгенерирует, отсмотрит кандидатов и отдаст три варианта с контакт-листами и отчётом.
  4. Попросить перегенерировать одну карту с комментарием, проверить цикл правок.
Проверяет: инструмент «под ключ» глазами продюсера, консистентность персонажей на золотых картах.
Фрейм 4

Модели по этапам: выбор, цена, качество

За тремя этапами стоит модель, и каждую можно сменить: планировщик (текст), генерация (картинки), контроль качества (зрение). Умолчание задаёт config.json, его перекрывают флаги и переменные окружения, а выше всех стоит пожелание продюсера в команде: «картинки через Gemini Pro, проверку подешевле» скилл переводит в настройки сам. Какая модель делала этап, записывается в файлы результата.

Цены сверены со страницами провайдеров 12.09.2026. Оценка качества экспертная, для нашей задачи: игрушечный 3D-стиль, референсы, персонажи, отсутствие текста. Замер даёт команда сравнения на одном плане.

Фрейм 5

Критерии успеха и стоимость

Тест считаем успешным, если

  • Не менее 7 из 10 карт Coolness проходят QA без правок и визуально ложатся рядом с оригиналами.
  • Персонажи на золотых картах Fishing узнаются как те же, что на референсах.
  • Сет с 4 кандидатами на карту укладывается в 2–3 доллара.
